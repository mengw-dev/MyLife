## 1. 产品概述

### 1.1 产品定位

MyLife 是一个以**人生时间线**为核心，将个人生活记录、知识管理、学习轨迹和重要人生事件整合在一起的个人成长记录系统。

### 1.2 产品目标

1. 降低日常记录成本。
2. 建立长期个人生活档案。
3. 建立持续积累的知识库。
4. 将生活经历和知识学习关联到统一时间线。
5. 支持搜索、备份、恢复和完整导出。
6. 帮助用户通过历史记录认识自己的变化。

### 1.3 产品版本

- V1.0 只开发 Web 在线版。
- Desktop 离线版作为后续独立项目，当前不纳入开发范围。

## 4. 人生时间线

时间线是整个系统的核心入口。

### 4.1 年份总览

默认展示用户有记录的年份，支持查看历史年份和未来年份。

每个年份展示：年份、年度标题、年度简介、代表照片、日记数量、学习记录数量、重要事件数量、是否存在记录。

用户可以编辑年度标题、简介和代表照片。

> **实现提示**：没有记录的未来年份可以由前端展示为空白节点，不要求数据库提前创建。

### 4.2 年度详情

点击年份进入年度详情，支持按内容类型筛选。

展示内容：

- 年度标题和简介
- 年度重要事件
- 12 个月的记录统计
- 每个月的日记数量
- 每个月的学习记录数量
- 每个月的重要事件数量

### 4.3 月份详情

展示指定月份的日历。每一天展示：是否有记录、日记数量、学习记录数量、重要事件数量。**重要事件使用独立标记**。点击日期进入日期详情。

### 4.4 日期详情

统一展示某一天的全部记录：

| 分组 | 内容 |
| --- | --- |
| 今日生活 | 日记列表、日记正文、相关照片、个人想法 |
| 今日学习 | 学习记录、学习内容、当时理解、遇到的问题、关联知识笔记 |
| 今日事件 | 事件标题、事件描述、相关照片、所属人生阶段 |

支持新增、编辑、删除和前后日期切换。

### 4.5 时间线筛选

支持按全部 / 生活 / 知识 / 重要事件筛选。筛选只改变展示内容，不修改原始业务数据。

## 5. 人生阶段

人生阶段由用户自行创建，例如：童年、小学、初中、高中、大学、工作。

| 字段 | 说明 |
| --- | --- |
| 阶段名称 | 阶段的展示名称 |
| 开始日期 | 阶段起始时间 |
| 结束日期 | 可空，为空表示仍在持续 |
| 阶段介绍 | 阶段文字描述 |
| 封面照片 | 可空 |
| 排序值 | 控制阶段显示顺序 |

业务规则：

1. 阶段可以跨越多个年份。
2. 阶段允许时间重叠。
3. 结束日期可以为空，表示仍在持续。
4. 日记、学习记录和事件可以关联阶段，也可以不关联。
5. 删除阶段时，不删除关联记录，只解除关联。
6. 支持调整阶段顺序。

## 6. 日记管理

### 6.1 日记功能

支持新建、查看、修改、删除、搜索、分页、日期筛选、阶段筛选、标签筛选、添加照片。

### 6.2 日记字段

| 字段 | 说明 |
| --- | --- |
| 标题 | 日记标题 |
| 正文 | 日记内容 |
| 记录日期 | 时间线归属依据，由用户指定 |
| 所属人生阶段 | 可空 |
| 标签 | 多标签 |
| 相关照片 | 多照片引用 |
| 创建时间 / 修改时间 | 审计字段 |

### 6.3 业务规则

1. 同一天允许存在多篇日记。
2. 日记日期由用户指定。
3. 修改日记日期后，时间线自动调整归属。
4. 日记可以不关联人生阶段。
5. 删除日记时，关联的重要事件保留，但解除日记关联。
6. 删除日记不应删除仍被其他记录引用的照片。

> **范围说明**：第一版采用简单文本编辑器，不要求复杂富文本编辑功能。

## 7. 个人知识库

### 7.1 知识分类

支持用户创建多级分类，支持创建、修改、删除、排序、多级嵌套。

```text
计算机                    其他
├── Java                ├── 数学
├── Go                  ├── 物理
├── MySQL               ├── 英语
├── Redis               └── 历史
├── Linux
└── 计算机网络
```

> **删除限制**：存在子分类或知识笔记时，不允许直接删除分类。

### 7.2 知识笔记

| 字段 | 说明 |
| --- | --- |
| 标题 | 笔记标题 |
| Markdown 正文 | 笔记内容 |
| 所属分类 | 必选 |
| 标签 | 多标签 |
| 相关照片 | 多照片引用 |
| 创建时间 / 修改时间 | 审计字段 |

支持新建、编辑、删除、搜索、分类筛选、查看历史学习记录。

### 7.3 学习记录

**学习记录与知识笔记分开存储。** 例如知识笔记《Java 线程池》对应的学习记录：

- 11 月 5 日：初次学习
- 11 月 8 日：理解核心参数
- 11 月 15 日：学习拒绝策略

| 字段 | 说明 |
| --- | --- |
| 学习标题 | 可选 |
| 学习日期 | 必选 |
| 学习内容 | 必选 |
| 当时理解 | 可选 |
| 遇到的问题 | 可选 |
| 关联知识笔记 | 可选，最多一篇 |
| 所属人生阶段 | 可选 |
| 标签 | 多标签 |

业务规则：

1. 一篇知识笔记可以关联多条学习记录。
2. 一条学习记录最多关联一篇知识笔记。
3. 学习记录可以不关联知识笔记。
4. 删除知识笔记时，保留学习记录。
5. 删除知识笔记后，学习记录保留原笔记标题快照。
6. 修改知识笔记不影响过去的学习记录。

## 8. 重要事件

用于记录值得长期保存的人生节点，例如：获得奖项、毕业、第一次实习、完成重要项目、旅行、人生转折。

| 字段 | 说明 |
| --- | --- |
| 事件标题 | 必选 |
| 事件日期 | 必选 |
| 事件描述 | 可选 |
| 所属人生阶段 | 可选 |
| 关联日记 | 可选，最多一篇 |
| 相关照片 | 多照片引用 |
| 标签 | 多标签 |

> **关联约束**：一条事件最多关联一篇日记。

## 9. 照片管理

支持上传照片、查看照片、添加描述、设置拍摄日期、关联日记 / 人生阶段 / 知识笔记 / 重要事件、删除照片。

业务规则：

1. 同一张照片可以被多个记录引用。
2. 照片文件只保存一份。
3. 删除照片前检查是否仍被引用。
4. 被引用的照片不允许直接删除。
5. Web 版照片必须经过登录和权限校验才能访问。
6. 不允许通过公开静态 URL 直接访问私人照片。

> **格式限制**：第一版只支持 JPEG、PNG、WebP、GIF，单张最大 10 MB。

## 10. 搜索与历史回顾

支持搜索：日记标题与正文、知识笔记标题与正文、学习记录、重要事件。

支持筛选：日期范围、记录类型、人生阶段、标签。

> **技术边界**：第一版使用 MySQL 查询实现，不引入 Elasticsearch。

## 11. 数据导出与备份

### 11.1 普通导出

支持导出：全部 / 指定日期范围的日记、全部 / 指定分类的知识笔记、学习记录、重要事件、人生阶段。格式：Markdown、JSON、ZIP。

### 11.2 AI 分析资料包

生成一个 ZIP，包含：日记、知识笔记、学习记录、人生阶段、重要事件、用户填写的照片描述、AI 分析提示词。

> **边界说明**：不接入 AI API，用户自行将资料包交给外部 AI。

### 11.3 完整备份

包含：全部业务数据、全部媒体文件、关联关系、数据版本信息、文件 SHA-256 校验清单。恢复前必须验证文件完整性和数据结构。

> **恢复边界**：恢复只替换当前用户的个人数据，不覆盖登录账号和密码。

## 12. 用户认证与安全

采用 Spring Security + Session。

功能：注册、登录、登出、获取当前用户、修改密码、注销账号。

安全要求：

1. 密码使用 BCrypt 哈希。
2. 使用 HTTPS。
3. 使用 CSRF 防护。
4. 使用 HttpOnly Cookie 保存 Session。
5. 当前用户 ID 从 Spring Security 获取。
6. 禁止信任客户端传入的 user_id。
7. 所有个人业务数据必须严格隔离。
8. 私人照片必须鉴权访问。
9. 防止暴力登录。
10. 不在日志中记录密码、日记正文和敏感文件内容。

> **资源隐藏**：不同用户访问彼此资源时统一返回 404。

## 14. 非目标

V1 不开发：AI 自动总结、AI 性格分析、知识图谱、社交分享、多人协作、多设备实时同步、语音转文字、Desktop 安装程序、复杂统计报表。

## 15. 验收标准

1. 可以完成注册、登录和登出。
2. 不同用户之间的数据完全隔离。
3. 可以完整管理人生阶段。
4. 可以从年份逐级进入日期。
5. 同一天允许多篇日记。
6. 同一知识笔记可以关联多次学习。
7. 删除知识笔记后，学习历史仍然存在。
8. 修改日记日期后，时间线正确更新。
9. 照片可以被多个记录引用。
10. 搜索结果正确。
11. Markdown 和 JSON 导出完整。
12. 完整备份能够恢复。
13. 页面刷新后数据仍然存在。
14. 删除账号后，按照规定清理用户数据。

> **V1.0 最终目标**：让用户能够长期记录生活和知识，并随时通过时间线找到过去的任何一天。
